# Personal Portfolio Website 🚀

Website portfolio pribadi super responsif dengan keamanan tingkat tinggi.

## 🔒 Fitur Keamanan
- Cloudflare Protection
- SSL/TLS Encryption
- Security Headers (CSP, XSS, dll)
- Email Obfuscation
- Rate Limiting
- Input Sanitization

## 🛠 Tech Stack
- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- Font Awesome Icons
